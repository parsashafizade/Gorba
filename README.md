# Tiny Yes

A polished bilingual collection of three mischievous, shareable asks: a raise, a new role,
and a coffee date. The current product is a frontend-only React application.

## Repository

- `frontend/` — React, TypeScript, Vite, Motion, localization, and tests
- `backend/` — reserved for a future service
- `mobile/` — reserved for a future native client
- `docs/` — product and architecture notes
- `gorba/` — untouched canonical bee-kitten source renders

## Run locally

```bash
cd frontend
npm install
npm run dev
```

Quality checks: `npm run check`. Production bundle: `npm run build`.
