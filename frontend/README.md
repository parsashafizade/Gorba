# Tiny Yes frontend

React 19 + TypeScript + Vite application. From the repository root, `npm run dev` starts this UI
and its result-notification API together. This workspace also provides `npm run test` for unit and
integration tests and `npm run build` for the production bundle.

Runtime mascot assets are semantic copies of the canonical files in `../gorba`. Components only
read them through `src/features/mascot/assets.ts`.
